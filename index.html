MOSS-VL Realtime Backend

MOSS-VL Realtime Backend#

Realtime video understanding with persistent WebSocket sessions, incremental visual KV, and dynamic multi-session scheduling. This repository is built on SGLang-Omni and uses the MOSS-VL-Realtime-SGLANG checkpoint.

For browser interaction, voice, and memory, see the companion Demo. The delivery guide contains launch commands, three public tests, and reference results.
